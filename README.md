# Grama-Vaxi 🐄💉

An Android application designed to help rural farmers manage livestock vaccination schedules efficiently.

---

## 📌 Introduction

Grama-Vaxi is a healthcare-focused Android application developed for rural livestock owners. In many villages, vaccination camp announcements are made only through loudspeakers, causing many farmers to miss important vaccination dates.

This app provides a simple digital solution by helping farmers:

- Register livestock details
- Track vaccination schedules
- Receive timely reminders
- Maintain digital health records

The application is designed with an offline-first approach and supports Kannada language for better accessibility.

---

## ❗ Problem Statement

Farmers in rural areas face several challenges:

- Limited communication channels
- No proper animal health records
- Missed vaccination schedules
- Lack of reminder systems

### Resulting Issues

- Unvaccinated livestock
- Rapid disease spread
- Financial losses for farmers

---

## ✅ Proposed Solution

Grama-Vaxi acts as a digital livestock healthcare assistant.

### Core Functionalities

- Digital animal health records
- Automatic vaccination tracking
- Reminder notifications
- Disease reporting support

---

# ✨ Features

## 🐂 Animal Ledger

- Register animals with:
  - Photo
  - Breed
  - Age
- Works like a digital health card

## 📅 Vaccine Calendar

- Auto-generates vaccination schedules
- Tracks vaccination history

## 🔔 Camp Alerts

- Sends reminders before vaccination camps
- Notifications generated in advance

## 🚨 Disease Alert

- Farmers can report sick animals
- Supports communication with veterinary services

# 🏗️ System Architecture

## Frontend

- Android Application
- Built using Kotlin
- Simple and accessible UI
- Kannada language support

## Backend

- Room Database
- Offline data storage

## Background Processing

- WorkManager
